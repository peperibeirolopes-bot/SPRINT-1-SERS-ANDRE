# Problema e Justificativa:

Com o crescimento da mobilidade elétrica, a demanda por eletropostos vem aumentando significativamente.

No entanto, muitos desses pontos de recarga ainda não possuem um sistema eficiente para gerenciar o consumo de energia, registrar as sessões de uso e organizar a cobrança dos usuários.

Essa falta de controle pode gerar desperdício energético, dificuldades operacionais e baixa eficiência no uso da infraestrutura.

Dessa forma, torna-se necessário o desenvolvimento de soluções simples e acessíveis que melhorem a gestão desses sistemas.

# Proposta e Impactos Esperados

O SmartCharge Lite é um programa em Python que propõe o gerenciamento básico de sessões de recarga em eletropostos.

A solução permite:

- registrar sessões de recarga

- calcular o consumo de energia

- gerar automaticamente o valor da cobrança

- organizar dados para melhor controle

Impactos esperados:

- melhoria na organização dos eletropostos

- maior controle sobre o consumo de energia

- redução de desperdícios

- base para evolução de sistemas mais avançados

# Tecnologias Utilizadas

- Python

- Lógica de programação

- Estruturas de dados simples

# Sustentabilidade e Energias Renováveis

O projeto está fundamentado nos princípios de eficiência energética e sustentabilidade.

Ao melhorar o controle do consumo de energia nos eletropostos, o sistema contribui para a redução de desperdícios e para um uso mais consciente dos recursos energéticos.

Além disso, a solução pode ser expandida futuramente para integração com fontes de energia renovável, como a energia solar, promovendo uma mobilidade elétrica mais limpa e sustentável.
